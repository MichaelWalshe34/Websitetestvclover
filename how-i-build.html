03 / HOW I BUILD

Decisions explained.
Results checked.

The most useful way to explain my approach is through specific decisions from this portfolio.

01

Define the purpose

Start with the visitor and the details they need to find.

The portfolio needs to make my career direction, project evidence, résumé and contact details easy to reach.

02

Choose a suitable structure

Use a structure that fits the problem and keeps the parts understandable.

The portfolio uses static pages with shared CSS and JavaScript, without requiring a database or a framework build.

03

Check the main routes

Check links, local assets and the interactions a visitor needs.

Page links, résumé loading, menu behaviour and required contact fields were checked in the local preview.

04

Inspect what the user sees

Check the interface as well as the underlying logic.

A cropped screenshot headline was found during the portfolio review. Its image sizing was corrected and the preview inspected again.

AI CONTRIBUTION

AI helped plan and implement this portfolio, generated much of the code, and assisted with documentation and checks. My role centred on its goals, constraints and direction. The case study explains that contribution.
